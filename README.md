# Shaiba LED Controller (Telegram Bot) 🍓🤖

Go-приложение для управления адресованной светодиодной лентой (WS2812B) на Raspberry Pi через Telegram-бота. 

Проект поддерживает смену цветов, отображение текста/чисел на 4-значном 7-сегментном дисплее из LED-сегментов, режимы радуги, температуры и интерактивные мини-игры (слот-машина 🎰).

---

## 🛠 Технологии и стек

* **Язык:** Go (Golang)
* **Telegram API:** `github.com/go-telegram-bot-api/telegram-bot-api/v5`
* **Hardware backend:** `github.com/rpi-ws281x/rpi-ws281x-go` (CGO)
* **Абстракция дисплея:** Conditional Compilation (Build Tags)

---

## 📐 Геометрия дисплея

* **Дисплей:** 4 семисегментных символа.
* **Сегмент:** 14 светодиодов.
* **Символ:** 7 сегментов (98 LED).
* **Всего диодов:** 392 LED.

## 🚀 Сборка и запуск

### 1. Локальная разработка и симуляция (Windows / macOS / Linux)

Для разработки и тестирования бота на ПК не требуется реальная лента и Raspberry Pi. В проекте встроен консольный симулятор.

Сборка обычной базовой версии (используется `open_null.go`):

```bash
go build -o app
./app
```

В консоли будет отображаться интерактивная цветная сетка сегментов в реальном времени:

```text
┌─────────────────────────────── LED FRAME ───────────────────────────────┐
│  █████     █████     █████     █████   │
│ █     █   █     █   █     █   █     █  │
│  █████     █████     █████     █████   │
│ █     █   █     █   █     █   █     █  │
│  █████     █████     █████     █████   │
└─────────────────────────────────────────────────────────────────────────┘
```

---

### 2. Сборка для Raspberry Pi (Железо)

Для работы с реальной лентой через WS2812B/DMA/PWM необходимо собирать проект с тегом `ws281x`:

```bash
# Сборка на самой Raspberry Pi
go build -tags ws281x -o app

# Запуск требует прав root для доступа к DMA/GPIO
sudo ./app
```

> **Совет:** Если нужно временно запустить бинарник, собранный с `-tags ws281x`, в режиме симулятора без обращения к физической ленте, используйте флаг среды:  
> `LED_SIM=1 sudo ./app`

## ⚙️ Развёртывание через systemd (Raspberry Pi)

1. Скопируйте собранный исполняемый файл `app` в папку `/opt/shaiba-led`:
   ```bash
   sudo mkdir -p /opt/shaiba-led
   sudo cp app /opt/shaiba-led/
   ```

2. Установите systemd юнит:
   ```bash
   sudo cp shaiba-led.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable --now shaiba-led
   ```

3. Просмотр логов:
   ```bash
   sudo journalctl -u shaiba-led -f
   ```

## 🕹 Команды бота

* `❤️` ... `🩷` — сменить цвет ленты.
* `🌈` — включить/выключить режим «Радуга».
* `🌡` — показать текущую температуру.
* `🎰` — запустить слот-машину.
* `/start` — приветствие и интерфейс.
* `/help` — справка по командам.
* `/set_new_year_date` — (Админ) установить дату обратного отсчёта.
